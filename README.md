## 代表项目

### 01｜智能驾驶员状态监测系统 V1.0

**技术栈：** Python · YOLOv8 · MediaPipe · InsightFace · PyQt5 · MySQL

**项目角色：** 独立开发

南京邮电大学《软件开发方法》课程项目，面向驾驶安全监测场景，设计并实现集驾驶行为检测、疲劳状态识别、人脸身份认证与告警管理于一体的桌面端应用。

**主要工作：**

- 基于 YOLOv8 实现使用手机、抽烟、喝水等驾驶行为检测。
- 使用 MediaPipe 提取人脸关键点，结合 EAR、MAR 及头部角度判断闭眼、打哈欠和低头状态。
- 采用 PyQt5、QThread 构建实时检测界面，支持摄像头与本地视频输入。
- 集成 InsightFace，实现驾驶员人脸注册和身份认证。
- 使用 MySQL 管理驾驶员信息、监测会话及报警记录。
- 设计连续帧判定与30秒告警冷却机制，过滤瞬时误检和重复报警。

**项目成果：**

- 实现6类异常状态检测、人脸认证与分级预警。
- 完成16个源代码文件，共6832行代码。
- 支持 Windows 平台离线部署。
- 独立申请并取得计算机软件著作权登记证书。

**软件著作权登记号：2026SR0795517**

### 02｜嵌入式系统应用开发

**技术栈：** Java · Android · Python · YOLO · OCR · ZXing · K210

**项目角色：** 3人团队项目负责人

2024年世界职业院校技能大赛嵌入式系统应用开发赛项参赛项目，围绕嵌入式小车控制、Android 终端应用及多场景 AI 视觉识别开展软硬件综合开发。

**主要工作：**

- **Android 应用开发：** 使用 Java 开发 Android APP，实现蓝牙、WiFi 双模连接、设备交互和小车摄像头画面实时拉流。
- **AI 视觉集成：** 在 APP 中集成百度 OCR 文字识别、ZXing 二维码识别和 YOLO 系列目标检测，实现7类目标识别。
- **K210 模块开发：** 使用 pyAI-K210 实现红绿灯 HSV 色域识别与黑白巡线功能。
- **方案优化：** 针对 K210 算力限制，将部分识别方案由 YOLOv3 调整为 HSV 颜色阈值方法，提升运行稳定性。
- **项目协作：** 负责团队任务协调，并在国赛技能展示环节担任主讲人，完成系统演示和技术讲解。

**竞赛成果：**

### 03｜变压器铁心横剪片料外观在线检测系统

**相关技术：** Labelme · 图像标注 · 数据治理 · U-Net 训练数据

**项目角色：** 数据负责人

针对变压器硅钢片传统人工抽检效率较低、检测误差较大的问题，项目通过工业线扫相机与机器视觉技术，实现产线在线尺寸检测。

本人主要负责**图像数据生产、标注标准制定、团队组织和数据质量管理**。

**主要工作：**

- 针对硅钢片高反光、边缘轮廓复杂等特点，独立完成约100张高分辨率图像试标。
- 使用 Labelme 制定图像轮廓标注规范，保障不同成员的标注一致性。
- 组织10余名成员开展数据标注、清洗、复核和交叉校验。
- 团队累计完成约1500张高分辨率图像的标注与复核。
- 为 U-Net 图像分割模型研发提供标准化训练数据，配合项目整体研发进度。

**项目成果：**

- 项目系统实现不超过0.2mm的检测误差。
- 相关技术成果形成第一作者论文1篇、授权发明专利1项。
- 获江苏省职业院校创新创业大赛三等奖。

### 04｜智能视觉割草机器人

**项目角色：** 视觉算法负责人

面向户外智能割草机器人应用场景，负责障碍物视觉检测、双目测距和边缘部署相关工作。

**主要工作：**

- 基于 YOLOv5 开发障碍物检测模块，识别人、宠物等6类常见目标。
- 针对户外强光、树影等复杂环境优化数据增强策略。
- 使用 SGBM 双目测距算法获取障碍物距离信息，参与视差参数调优。
- 设计串口通信接口，向底层控制模块发送障碍物类别、距离和坐标信息。
- 将视觉算法向地平线 X3 边缘芯片迁移，完成 INT8 量化部署。

**项目成果：**

完成视觉感知模块开发及边缘端联调，支持机器人户外场景障碍物检测与测距。
